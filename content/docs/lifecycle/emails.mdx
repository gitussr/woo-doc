<PageMeta priority="P1" audience="Intermediate → Advanced" />

WooCommerce sends transactional email itself — one class per email type,
triggered by [order status transitions](/docs/lifecycle/orders#the-transition-hook-family)
and a few account events. This page is the structure and the hooks; it does
not cover deliverability (SMTP, SPF/DKIM), which is a hosting concern.

## The registry

The class list is filterable:

```php
add_filter( 'woocommerce_email_classes', function ( $emails ) {
    $emails['WD_Email_Backorder'] = include __DIR__ . '/class-wd-email-backorder.php';
    return $emails;
} );
```

## Built-in emails and their triggers

| Email (id) | Sent to | Triggered by |
| --- | --- | --- |
| New order (`new_order`) | Admin | Order enters `processing` (and other paid statuses) |
| Cancelled order (`cancelled_order`) | Admin | Order → `cancelled` |
| Failed order (`failed_order`) | Admin | Order → `failed` |
| Processing order (`customer_processing_order`) | Customer | Order → `processing` |
| Completed order (`customer_completed_order`) | Customer | Order → `completed` |
| Refunded order (`customer_refunded_order`) | Customer | Order refunded (full or partial) |
| Order on-hold (`customer_on_hold_order`) | Customer | Order → `on-hold` |
| Invoice / order details (`customer_invoice`) | Customer | Sent manually from the order screen (also used for pending-payment) |
| Customer note (`customer_note`) | Customer | `$order->add_order_note( $text, true )` |
| Reset password (`customer_reset_password`) | Customer | Password reset request |
| New account (`customer_new_account`) | Customer | Account created |

Override any of these via the theme's `woocommerce/emails/` folder, exactly as
for [storefront templates](/docs/development/templates). The header image and
accent colour are settings, not template edits
(`woocommerce_email_header_image`, `woocommerce_email_base_color`, …).

## The main hooks

| Hook | Use |
| --- | --- |
| `woocommerce_email_classes` | Register a custom email |
| `woocommerce_email_recipient_<id>` | Change who an email goes to |
| `woocommerce_email_subject_<id>` / `woocommerce_email_heading_<id>` | Change subject / heading |
| `woocommerce_email_before_order_table` / `woocommerce_email_after_order_table` | Inject content around the order summary |
| `woocommerce_email_order_meta` | Add rows after the order table |
| `woocommerce_email_headers` | Add CC/BCC or custom headers |
| `woocommerce_mail_content` | Filter the final rendered HTML |

<VerifyNote>confirm these hook names and parameters for 11.0.1</VerifyNote>

## The Block email editor

<VersionNote version="WooCommerce 11.0">
  WooCommerce 11.0 ships an **experimental block-based email editor** alongside
  the classic per-email settings. Where enabled, email bodies are edited as
  blocks rather than by overriding PHP templates. Treat it as unstable and
  keep template overrides as the supported path for now.
  <VerifyNote>the feature flag / settings location for the block email editor
  in 11.0.1</VerifyNote>
</VersionNote>
