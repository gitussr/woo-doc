<PageMeta priority="P1" audience="Intermediate → Advanced" />

A product is the catalog entity everything else in WooCommerce is priced and
stocked against. This page covers what a product *is* at runtime, how the
price you see is assembled, and how stock is tracked. The storage layout is in
[WooCommerce Data Model](/docs/foundations/woocommerce-data-model#products);
this page is about behavior.

## Product types

The `product_type` taxonomy term on the product selects a CRUD subclass:

| Type | Class | What it is |
| --- | --- | --- |
| `simple` | `WC_Product_Simple` | One SKU, one price, optional stock |
| `variable` | `WC_Product_Variable` | A parent with attributes; buyable variations are its children |
| `grouped` | `WC_Product_Grouped` | A display container that links to other simple products; not itself purchasable |
| `external` | `WC_Product_External` | An "affiliate" product — the add-to-cart button links off-site |

Extensions register more (`subscription`, `bundle`, `booking`, …) by adding a
`product_type` term and hooking `woocommerce_product_class`
(`$classname, $product_type, $post_type, $product_id`), which
`WC_Product_Factory` applies when resolving the class for a product.

Get the right object with `wc_get_product( $id )` — it returns the correct
subclass. Check with `$product->get_type()` or `$product->is_type( 'variable' )`.

## The price pipeline

A product carries three stored price fields and one computed one:

| Field | Getter | Meaning |
| --- | --- | --- |
| Regular price | `get_regular_price()` | The normal price |
| Sale price | `get_sale_price()` | The discounted price, if any |
| Active price | `get_price()` | Sale price when a sale is on, else regular price |
| — | `get_price_html()` | The formatted string with currency, "was/now", suffix |

<SafetyLevel level="recommended">
  Change the <em>value</em> with <code>woocommerce_product_get_price</code> /
  <code>_get_regular_price</code> / <code>_get_sale_price</code> (and the
  <code>_variation_</code> equivalents). Change the <em>display</em> with
  <code>woocommerce_get_price_html</code>. See
  [Filters](/docs/development/filters#the-wc_data-dynamic-getter-filters).
</SafetyLevel>

<SafetyLevel level="risky">
  For per-customer or per-cart pricing, do <strong>not</strong> filter
  <code>get_price</code> globally — it fires everywhere and you will fight
  caching and admin screens. Set the line price during cart calculation
  instead (see [Cart](/docs/lifecycle/cart#changing-a-line-price)).
</SafetyLevel>

Whether a sale is "on" also depends on the sale schedule
(`_sale_price_dates_from` / `_sale_price_dates_to`). `wc_scheduled_sales()`
runs on the **daily** `woocommerce_scheduled_sales` cron event to start and
end scheduled sales — so a sale ending mid-day is not cleared to the minute.

Stock management overall is gated by the per-product `_manage_stock` and the
store-wide `woocommerce_manage_stock` option.

<Callout type="info">
  WooCommerce 11.0 enables **product object caching by default for new
  stores** and includes query optimizations for large catalogs and variable
  products. Reads of `wc_get_product()` may be served from the object cache;
  writes invalidate it.
</Callout>

## Extension surface

| You want to… | Use |
| --- | --- |
| Add a field to the product editor | Render on `woocommerce_product_options_general_product_data` / `_pricing` / `_inventory_product_data` / `_shipping_product_data` / `_advanced` (or add a tab via `woocommerce_product_data_tabs` + `woocommerce_product_data_panels`); save on `woocommerce_admin_process_product_object` (set on the `$product` object) or `woocommerce_process_product_meta` |
| Add a product type | Register a `product_type` term + a `WC_Product_*` subclass + `woocommerce_product_class` |
| Change catalog visibility / query | `woocommerce_product_query`, the `product_visibility` taxonomy |
| Change purchasability | `woocommerce_is_purchasable`, `woocommerce_variation_is_purchasable` |
| React to a stock change | `woocommerce_product_set_stock`, `woocommerce_low_stock`, `woocommerce_no_stock`, `woocommerce_product_set_stock_status` |

The Product Editor beta was **fully removed in WooCommerce 11.0** — the
classic metabox above is the only product-editor extension surface.
